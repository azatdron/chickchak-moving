CHIK-CHAK MOVING v1.0
1. Upload index.html and the assets folder to the root of a public GitHub repository.
2. In Settings > Pages, select Deploy from a branch, main, /(root), Save.
3. Add your own images: assets/hero.jpg, slide2.jpg, slide3.jpg, work1.jpg, work2.jpg, work3.jpg.
4. Edit CONFIG near the bottom of index.html to set Facebook, Instagram, reviews and WhatsApp URLs.
5. For custom domain, configure DNS and GitHub Pages custom domain after purchasing the domain.
NOTE: Price ranges are example estimates, not a binding quote. WhatsApp message does not send automatically; user confirms in WhatsApp.
